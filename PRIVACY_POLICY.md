# Development privacy statement

Square Chess stores games and settings locally on the device. This development build contains no account, advertisements, analytics SDK or Internet permission. Android cloud backup is disabled in the manifest. Development logs may contain game moves/FEN for testing, not credentials.

This is a development statement, not a completed Play Data Safety audit. Before release, audit the final dependency/permission graph and export/share behaviour, provide a support contact and publish an accessible policy URL. Users will explicitly choose any exported file destination.
