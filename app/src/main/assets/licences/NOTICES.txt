## Fairy-Stockfish (chess engine)

- This app uses Fairy-Stockfish with classical evaluation. No NNUE network is included.
- Source: lichess-org/dart-multistockfish commit 896c3884921ae1d775fcd3088ddcd1559fb87308, package multistockfish_variant 0.4.0.
- Engine base: fairy-stockfish/Fairy-Stockfish 2b5d95121664fe564779d84aac171f16b725c147, with the Lichess private-I/O and namespace patches.
- Square Chess changes: JNI glue (native/fairy_bridge.cpp), a UCI option-order reset for engine restarts (src/ucioption.cpp), and a thread-safe output buffer that stops a duplicated bestmove (sfio.cpp). No move-selection or evaluation changes. Difficulty levels set only the engine's own Skill Level and MultiPV options.
- Licence: GNU GPL v3 or later. Upstream copyright notices, AUTHORS and the GPL text are retained.
- Corresponding source must match this exact build, including the app, JNI glue, engine modifications and build scripts.
