# Security policy

## Reporting a vulnerability

Please report security problems privately by email to **support@dataespresso.com** with "Security" in the subject. Do not open a public issue. Include the app version, the device, and the steps to reproduce the problem.

You will get an answer within 7 days. When a fix is ready, it is released on all channels and the report is credited if you wish.

## Scope

Square Chess has no network access, no account and no server, so the main risks are in local data handling:

- files that the app reads (PGN and FEN import) and writes (export, share);
- the saved-game database;
- the native chess engine (`native/`).

## Supported versions

Only the newest release receives security fixes.
